## R4 — Bounded queries and literal title matching

**Decision**: One structured `search_movies` tool handles title/filter/recommendation reads.
Arguments are typed criteria, never model-supplied MQL, collection names or credentials.
Application code creates an allowlisted filter and fixed projection, sort and limit.
Case-insensitive literal title containment uses an escaped regex, not fuzzy/semantic search;
no index creation or full catalog materialization. This feature requires exact literal
substring semantics, not a new fuzzy/relevance-search capability.

**Rationale**: [Query documents](https://www.mongodb.com/docs/languages/python/pymongo-driver/current/crud/query/),
[cursor API](https://pymongo.readthedocs.io/en/4.18.3/api/pymongo/cursor.html),
[regex](https://www.mongodb.com/docs/manual/reference/operator/query/regex/) and
[numeric types](https://www.mongodb.com/docs/manual/reference/operator/query/type/)
provide the driver/server operations. Escape metacharacters; validate strings/arrays/scalars
before constructing queries. For filtered numeric fields require scalar, finite valid
numeric values, excluding strings, booleans, arrays, NaN and infinities; do not rely solely
on query `$type: 'number'`, which can also match array elements. Type-bracketed predicates
and final record validation must agree before limiting eligible results. Exclude empty or
nonstring titles. Define all eligibility predicates before the server limit; post-limit
discarding must not underfill a request when sufficient valid matches exist.

Projection: `_id`, `title`, `year`, `genres`, `imdb.rating`, `plot`; server truncation of
display text is permitted without changing matching semantics. Return only the effective
limit (default 5, max 10), no count of the entire catalog. Stable default order is title then
source `_id`; high-rating order is numeric IMDb descending then title and `_id`.
Unanchored regex can scan the sample collection; bounded time/output does not promise an
index-efficient query. Do not add Atlas Search/vector indexes for this small feature.

**Alternatives considered**: Raw MQL tools, external movie APIs, client-side catalog scans,
embeddings, fuzzy title matching and silently relaxed filters: rejected.

prompt-only enforcement is not sufficient.

document recording and background extraction. The starter Daily prompt's automatic profile
guidance must be replaced. Native history is not equivalent to explicitly querying profiles.
Same-session criteria live in serializable graph state and are replaced only when explicitly
overridden; new/missing context prompts clarification.

**Alternatives considered**: Disabling extraction/memory, zero-retention promises, custom
profile stores or exposing every profile tool and relying only on prompts: rejected.
